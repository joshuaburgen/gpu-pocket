# GPU Pocket 手机端

Flutter 原生 Android / iOS 客户端。使用 Dart 3.10 或更新版本和当前 Flutter stable；本次验证版本为 Flutter 3.47.9 / Dart 3.13.7。安全存储使用 flutter_secure_storage 11.2.0。

运行 `flutter pub get`、`flutter analyze`、`flutter test` 后，通过 `flutter run` 启动。Android APK 构建需要 Android SDK / JDK，iOS 构建与签名需要 macOS / Xcode。Android 最低 API 23，iOS 工程目标为 15.0。iOS 已配置 Keychain entitlement，真机仍需设置自己的签名团队。

App 默认使用 HTTPS，不接受远端 HTTP 或无效证书。`http://127.0.0.1:8787` 用于调试；Android 真机／模拟器可用 `adb reverse tcp:8787 tcp:8787` 将其连接至电脑开发端口。根目录 README 说明了演示服务器与 SSH 转发方式。

监控每 15 秒刷新，编辑文本时暂停界面轮询，进入后台停止轮询。GPU 卡片列出 GPU 进程（不含 Xorg、Sunlogin、Chrome/Chromium、Cursor）、PID、显存用量和可执行文件路径，并标出进程是否位于 `Tongji-Wang/gpu`。前台发现新出现的 GPU 目录外进程时显示提示；后台推送要求服务器服务账号、手机 Firebase 客户端配置和通知权限均已设置。设置页提供 Kryptex 与 NiceHash 账户预设，选择账户时保留各设备已有的 worker 后缀（如 `.3080ti-gpu0`）；也可编辑完整的 `账户.worker`。控制卡片用绿色表示 GPU Pocket 矿工运行、黄色表示有其他进程占用、灰色表示空闲；外部进程状态无法确认时显示橙色。控制页区分暂存配置与运行记录，应用操作需要确认，受服务端控制开关与版本检查约束。CPU 挖矿位于独立控制面板，配置与服务不影响 GPU0/GPU1；线程比例默认 50%，可调 1–100%，但 SRBMiner 将其作为线程提示而非严格系统级 CPU 限额。系统安全存储仅保存服务器 URL 与 API 令牌，不保存 SSH 密钥、矿池私钥或助记词。

监控页点击 GPU 卡片可选择全量启动或停止；手动节制启动暂时停用，因为 SRBMiner 算法强度不限制 GPU 利用率或功耗，后端也拒绝新的节制启动请求。已经在运行的矿工不会因该功能停用而自动停止。全量手动启动允许与其他 GPU 任务共存，但不会停止其他进程，可能出现资源争用。空闲自启计时来自服务器策略循环：该卡利用率低于 25% 且没有其他计算进程时计时，连续 10 分钟后按全量强度 31 启动；打开监控页不会重置或开始该计时。深夜模式也会避让其他计算进程，并保留每 5 秒轮询的可用显存保护。点击 CPU 卡片可调整线程比例并启动、重启或停止。CPU 概览显示整机 CPU 使用率；SRBMiner 线程比例是工作线程数提示，不是整机 CPU 硬限额，矿池未连接时也不会产生预期的挖矿负载。SRBMiner 全量启动与自动自启固定使用强度 31，不设置 GPU 功耗上限。GPU Pocket 已有的节制模式运行记录仍会显示紫色，全量模式显示绿色。自动策略仅保留空闲自启和深夜模式；GPU 面板保持对应状态色，启用自动控制时仅在边缘显示 1.5 像素彩虹线；红色故障状态会附带经过筛选的服务错误原因。控制页可设置最低可用显存和自动模式参数。

主导航中的“AI任务”显示默认 GPU Pocket 工作目录和任务输入框。任务提交只有在安全的本机 AI 桥接服务就绪后才能启用；当前项目尚无此桥接服务，因此不会通过 Cloudflare 暴露任意命令执行接口。连接设置可从右上角齿轮进入。

Pearl GPU 与 CPU 配置由服务端固定适配到管理员配置的 SRBMiner；手机只选择服务器允许的配置，不提交任意矿工命令。Krig 1.5.12 切换因服务器 glibc 不兼容而暂停，生产仍使用 SRBMiner。
